## О проекте

**TimeShift** — собственный одностраничный макет, разработанный для практики работы с библиотекой **Bootstrap**.

Помимо Bootstrap, в проекте использовалась библиотека **jQuery** для обработки пользовательских действий и реализации интерактивных элементов интерфейса.
